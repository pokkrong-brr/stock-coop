# คู่มือติดตั้ง สต็อกสหกรณ์สระว่ายน้ำ (หน้าเว็บบน GitHub · ข้อมูลใน Google Sheets)

```
มือถือ / คอม  ──►  GitHub Pages (หน้าเว็บ)  ──►  Apps Script /exec (API)  ──►  Google Sheets (ข้อมูลทั้งหมด)
```

- **หน้าเว็บ** อยู่บน GitHub Pages ฟรี ลิงก์สั้น ติดตั้งเป็นแอปบนมือถือได้
- **ข้อมูลทั้งหมด** (สินค้า การขาย บัญชีผู้ใช้ ฯลฯ) อยู่ใน Google Sheets ของคุณเท่านั้น GitHub ไม่เก็บข้อมูลใดๆ
- ใช้เวลาติดตั้งประมาณ **30–40 นาที** ทำบนคอมพิวเตอร์ (Chrome) จะง่ายที่สุด

## สิ่งที่ต้องมี
- บัญชี Google 1 บัญชี เป็น "เจ้าของระบบ" (แนะนำบัญชีของสหกรณ์ ไม่ใช่บัญชีส่วนตัวของครูคนใดคนหนึ่ง)
- บัญชี GitHub ฟรี (สมัครที่ https://github.com/signup)
- ไฟล์ชุดนี้ (`stock-coop-github.zip`) **แตกไฟล์ (Extract/Unzip) ไว้ในเครื่องก่อน**

## ไฟล์ในชุดนี้
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าโปรแกรมทั้งหมด |
| `config.js` | **ไฟล์เดียวที่ต้องแก้**: ใส่ลิงก์ Apps Script |
| `setup.html` | หน้าทดสอบการเชื่อมต่อ ใช้ตอนติดตั้ง |
| `manifest.webmanifest`, `icons/`, `sw.js` | ทำให้ติดตั้งเป็นแอปบนมือถือ เปิดเร็ว และเปิดได้แม้เน็ตหลุด |
| `apps-script/Code.gs` | โค้ดฝั่ง Google (ต้องวางใน Apps Script) |
| `apps-script/appsscript.json` | ไฟล์ตั้งค่าโปรเจ็กต์ (เขตเวลา Bangkok, V8, เว็บแอป) |

# ส่วนที่ 1: Google Sheets + Apps Script (ประมาณ 15 นาที)

> **เคยติดตั้งเวอร์ชันก่อนแล้ว?** ใช้ชีตเดิมได้เลย ข้ามข้อ 1.1–1.2 ไปทำ 1.3 ได้ ข้อมูลเดิมไม่หาย

### 1.1 สร้างไฟล์ Google Sheets
1. ล็อกอินบัญชี Google ของเจ้าของระบบ แล้วเปิด https://sheets.new
2. คลิกชื่อไฟล์มุมซ้ายบน ("สเปรดชีตที่ไม่มีชื่อ") เปลี่ยนเป็น **สต็อกสหกรณ์สระว่ายน้ำ**

### 1.2 ตั้งเขตเวลาของไฟล์
1. เมนู **ไฟล์ > การตั้งค่า**
2. ภาษา: **ไทย** · เขตเวลา: **(GMT+07:00) Bangkok** > **บันทึกการตั้งค่า**

### 1.3 เปิด Apps Script
1. เมนู **ส่วนขยาย > Apps Script** (เปิดแท็บใหม่)
2. คลิกชื่อ "โปรเจ็กต์ที่ไม่มีชื่อ" ด้านบน เปลี่ยนเป็น **สต็อกสหกรณ์** > เปลี่ยนชื่อ

### 1.4 วางไฟล์ตั้งค่า `appsscript.json` (ตั้งเขตเวลาให้อัตโนมัติ)
1. แถบซ้ายสุด กดไอคอนเฟือง ⚙️ **การตั้งค่าโปรเจ็กต์**
2. ติ๊ก ☑ **แสดงไฟล์ Manifest "appsscript.json" ในเครื่องมือแก้ไข**
3. กลับไปที่ไอคอน **< >** (เครื่องมือแก้ไข) จะเห็นไฟล์ `appsscript.json` คลิกเปิด
4. ลบข้อความเดิมทั้งหมด (Ctrl+A แล้ว Delete) วางข้อความจากไฟล์ `apps-script/appsscript.json` ในชุดนี้
5. กด **บันทึก** (ไอคอนแผ่นดิสก์ หรือ Ctrl+S / ⌘+S)

### 1.5 วางโค้ด `Code.gs`
1. คลิกไฟล์ **Code.gs** ทางซ้าย
2. ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดจาก `apps-script/Code.gs` ในชุดนี้ (เปิดไฟล์ด้วย Notepad/TextEdit แล้วคัดลอกทั้งหมด)
3. กด **บันทึก** ต้องไม่มีข้อความสีแดงขึ้น
   > ถ้ามีไฟล์ `Index.html` จากเวอร์ชันเก่าอยู่ เก็บไว้ได้ ไม่มีผลกับเวอร์ชัน GitHub

### 1.6 รัน `setup` ครั้งแรก (สร้างแท็บข้อมูล + ขออนุญาต)
1. แถบด้านบนเครื่องมือแก้ไข มีช่องเลือกฟังก์ชัน เลือก **setup** แล้วกด **▶ เรียกใช้ (Run)**
2. จะขึ้นหน้าต่าง "ต้องได้รับการให้สิทธิ์" > **ตรวจสอบสิทธิ์** > เลือกบัญชีเจ้าของระบบ
3. ถ้าขึ้น **"Google ยังไม่ได้ยืนยันแอปนี้"** ให้กด **ขั้นสูง** > **ไปที่ สต็อกสหกรณ์ (ไม่ปลอดภัย)**
   (ขึ้นเพราะเป็นโค้ดที่เราเขียนเอง ไม่ได้ส่งให้ Google ตรวจ เป็นเรื่องปกติ)
4. กด **อนุญาต** สิทธิ์ที่ขอและเหตุผล:
   - ดู แก้ไข สร้าง สเปรดชีต → บันทึกข้อมูลลงชีตนี้
   - ส่งอีเมลในนามคุณ → อีเมลแจ้งสินค้าใกล้หมด / สรุปยอด
   - ดู แก้ไข ไฟล์ใน Google ไดรฟ์ → สำรองไฟล์ชีตทุกสัปดาห์ และตรวจการแชร์ไฟล์
   - เรียกใช้เมื่อคุณไม่อยู่ → งานตั้งเวลา (08:00, 18:00, สำรองวันอาทิตย์)
5. รอจน "บันทึกการดำเนินการ" ขึ้นว่า **การดำเนินการเสร็จสมบูรณ์**
6. กลับไปแท็บ Google Sheets ต้องเห็นแท็บ: **สินค้า · ความเคลื่อนไหว · ตั้งค่า · เจ้าหน้าที่ · ผู้จำหน่าย · ใบสั่งซื้อ · ปิดยอด · บันทึกการแก้ไข · รูปสินค้า**

### 1.7 เผยแพร่เป็นเว็บแอป (Deploy)
1. ใน Apps Script กดปุ่มสีน้ำเงิน **การทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. ที่ "เลือกประเภท" กดเฟือง ⚙️ > เลือก **เว็บแอป**
3. ตั้งค่า:
   - คำอธิบาย: `เวอร์ชัน 1`
   - ดำเนินการในฐานะ: **ฉัน (อีเมลเจ้าของระบบ)**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
4. กด **ทำให้ใช้งานได้ (Deploy)** (ถ้าขอสิทธิ์อีก ให้อนุญาตแบบข้อ 1.6)
5. **คัดลอก "URL ของเว็บแอป"** ที่ลงท้ายด้วย `/exec` เก็บไว้ (ใช้ในส่วนที่ 2)

### 1.8 ทดสอบลิงก์
เปิดแท็บใหม่ วางลิงก์แล้วต่อท้ายด้วย `?api=ping` เช่น
`https://script.google.com/macros/s/AKfy.../exec?api=ping`
ต้องเห็น `{"ok":true,"r":"สต็อกสหกรณ์ พร้อมใช้งาน"}`

> **ใช้บัญชีโรงเรียน (Google Workspace) แล้วไม่มีตัวเลือก "ทุกคน"** แปลว่าผู้ดูแลระบบของโรงเรียนปิดไว้
> ทางแก้: ขอผู้ดูแล Google Workspace เปิด "อนุญาตให้ผู้ใช้แชร์เว็บแอปกับทุกคน" หรือใช้บัญชี Gmail ของสหกรณ์เป็นเจ้าของชีตแทน
> (ปลอดภัย เพราะทุกคำสั่งต้องเข้าสู่ระบบด้วยบัญชีของโปรแกรมก่อน และตรวจสิทธิ์ที่ฝั่ง Google ทุกครั้ง)

# ส่วนที่ 2: ขึ้นหน้าเว็บบน GitHub Pages (ประมาณ 10 นาที)

### 2.1 สร้าง repository
1. ล็อกอิน https://github.com > มุมขวาบนกด **+** > **New repository**
2. Repository name: `stock-coop` (ใช้ตัวอังกฤษ ไม่เว้นวรรค)
3. เลือก **Public** (บัญชีฟรีเปิด Pages ได้เฉพาะ Public · ไม่มีข้อมูลร้านอยู่ใน GitHub จึงไม่เป็นปัญหา)
4. ไม่ต้องติ๊กอะไรเพิ่ม > **Create repository**

### 2.2 อัปโหลดไฟล์
1. ในหน้า repository ที่เพิ่งสร้าง กดลิงก์ **uploading an existing file**
2. เปิดโฟลเดอร์ที่แตกไฟล์ไว้ เลือก **ทุกไฟล์และทุกโฟลเดอร์** (`index.html`, `config.js`, `setup.html`, `sw.js`, `manifest.webmanifest`, `README.md`, โฟลเดอร์ `icons` และ `apps-script`) ลากมาวางในหน้าเว็บ
3. รอให้รายชื่อไฟล์ขึ้นครบ > เลื่อนลงกด **Commit changes**
   > ไฟล์ซ่อน `.nojekyll` ไม่ต้องอัปโหลดก็ได้

### 2.3 ใส่ลิงก์ Apps Script ใน `config.js`
1. ในรายการไฟล์บน GitHub คลิก **config.js** > กดไอคอนดินสอ ✏️ (Edit this file)
2. แก้บรรทัดสุดท้ายเป็น (วางลิงก์จากข้อ 1.7 ระหว่าง `' '`)
   ```js
   window.STOCK_API = 'https://script.google.com/macros/s/AKfy.../exec';
   ```
3. กด **Commit changes...** > **Commit changes**

### 2.4 เปิด GitHub Pages
1. แท็บ **Settings** ของ repository > เมนูซ้าย **Pages**
2. Build and deployment > Source: **Deploy from a branch**
3. Branch: **main** · โฟลเดอร์: **/ (root)** > **Save**
4. รอ 1–3 นาที แล้วรีเฟรชหน้า จะขึ้น **"Your site is live at https://ชื่อบัญชี.github.io/stock-coop/"**

### 2.5 ทดสอบการเชื่อมต่อ
เปิด `https://ชื่อบัญชี.github.io/stock-coop/setup.html` > กด **ทดสอบการเชื่อมต่อ**
ต้องขึ้น **✓ เชื่อมต่อสำเร็จ และ API ตอบถูกต้อง** (ถ้าไม่ผ่าน ดูส่วนที่ 7)

# ส่วนที่ 3: ตั้งค่าครั้งแรก (ประมาณ 10 นาที)
1. เปิด `https://ชื่อบัญชี.github.io/stock-coop/`
2. เข้าสู่ระบบ: ชื่อผู้ใช้ `admin` รหัสผ่าน `admin1234`
3. ระบบจะ **บังคับตั้งรหัสผ่านใหม่** (อย่างน้อย 8 ตัว ห้ามเดาง่าย) จดเก็บไว้ในที่ปลอดภัย
4. ไปที่ **ตั้งค่า** แล้วทำตามลำดับ:
   1. **ข้อมูลร้าน**: ชื่อร้าน
   2. **หมวดหมู่สินค้า**: แก้ให้ตรงกับร้าน
   3. **แจ้งเตือนทางอีเมล**: ใส่อีเมลผู้รับ > ติ๊กเลือกการแจ้งเตือน > กด **ตั้งเวลางานอัตโนมัติ** > กด **ส่งอีเมลทดสอบ**
   4. **เงินสดและสำรองข้อมูล**: ใส่เงินทอนตั้งต้น > ติ๊กสำรองอัตโนมัติ > กด **สำรองข้อมูลตอนนี้**
   5. **บัญชีเจ้าหน้าที่**: เพิ่มบัญชีครู/นักเรียนที่ช่วยขาย แล้วติ๊กสิทธิ์ให้แต่ละคน
5. ไปที่ **รายการสินค้า** > **เพิ่มสินค้า** ใส่สินค้าทั้งหมดพร้อมยอดยกมา (มีรหัสบาร์โค้ดใส่ช่องรหัสได้)
6. กลับไป **ตั้งค่า > ตรวจสุขภาพระบบ** > กด **ตรวจตอนนี้** เป้าหมาย **ทุกข้อเป็น ✓ (100/100)** ถ้ามีข้อใดไม่ผ่าน ระบบบอกวิธีแก้ไว้ใต้ข้อนั้น

### 3.1 ล็อกความปลอดภัยของบัญชี Google (สำคัญมาก)
คนที่แก้ไฟล์ชีตได้โดยตรง จะข้ามระบบสิทธิ์ในโปรแกรมได้ทั้งหมด จึงต้อง:
1. ในไฟล์ Google Sheets กดปุ่ม **แชร์** > "สิทธิ์เข้าถึงทั่วไป" ต้องเป็น **จำกัด**
   และรายชื่อผู้แก้ไขเหลือเฉพาะผู้ดูแล 1–2 คน (เจ้าหน้าที่ขายของ **ไม่ต้อง** มีสิทธิ์ในชีต)
2. เปิด **การยืนยันแบบ 2 ขั้นตอน** ของบัญชีเจ้าของระบบที่ https://myaccount.google.com/signinoptions/two-step-verification

# ส่วนที่ 4: ติดตั้งเป็นแอปบนมือถือ
- **iPhone / iPad**: เปิดลิงก์ใน **Safari** > ปุ่มแชร์ (สี่เหลี่ยมมีลูกศรขึ้น) > **เพิ่มไปยังหน้าจอโฮม** > เพิ่ม

# ส่วนที่ 5: ทดสอบก่อนใช้งานจริง (วันแรก ประมาณ 15 นาที)
ทำครบทุกข้อด้วยมือถือจริงอย่างน้อย 2 เครื่อง ติ๊กเมื่อผ่าน:
- [ ] เข้าสู่ระบบด้วยบัญชีผู้ดูแล และบัญชีเจ้าหน้าที่ได้ เมนูของเจ้าหน้าที่แสดงตามสิทธิ์ที่ติ๊กไว้
- [ ] ขายสินค้า 1 บิล (เงินสด) และ 1 บิล (โอน) → ดูในชีต "ความเคลื่อนไหว" มีแถวใหม่ภายในไม่กี่วินาที
- [ ] เปิดโหมดเครื่องบิน ขาย 1 บิล → ป้ายขึ้น "ออฟไลน์ · รอส่ง 1" → ปิดโหมดเครื่องบิน → ป้ายกลับเป็น "บันทึกครบแล้ว"
- [ ] 2 เครื่องขายสินค้าตัวเดียวกันพร้อมกัน → ยอดคงเหลือในชีตถูกต้อง
- [ ] คืนสินค้าบางส่วนจากบิล → ยอดขายวันนี้ลดลง สต็อกกลับมา
- [ ] รับสินค้าเข้า / ตัดออก / ตรวจนับ → ยอดคงเหลือถูกต้อง
- [ ] ปิดยอดเงินสดวันนี้ → ชีต "ปิดยอด" มีแถวใหม่
- [ ] รายงาน: เลือก "ยอดขายรายหมวด" และ "รายการบิล" ตัวเลขตรงกับที่ขายทดสอบ
- [ ] ได้รับอีเมลทดสอบ และไฟล์สำรองอยู่ในโฟลเดอร์ Google ไดรฟ์
- [ ] ตรวจสุขภาพระบบได้ 100/100
- [ ] ลบข้อมูลทดสอบ: ในชีต "ความเคลื่อนไหว" ลบแถวทดสอบ แล้วตั้งยอดคงเหลือด้วย "ตรวจนับ" ให้ตรงของจริง

# ส่วนที่ 6: การอัปเดตเวอร์ชันในอนาคต
- **หน้าเว็บ (`index.html`)**: GitHub > คลิกไฟล์ > ✏️ หรือ Add file > Upload files ทับ > Commit · มือถือจะได้หน้าใหม่เมื่อเปิดแอปครั้งถัดไป (ปิดแล้วเปิด 1–2 ครั้ง)
- **โค้ด Google (`Code.gs`)**: วางทับใน Apps Script > บันทึก > **การทำให้ใช้งานได้ > จัดการการทำให้ใช้งานได้** > ✏️ แก้ไข > เวอร์ชัน: **เวอร์ชันใหม่** > ทำให้ใช้งานได้
  > ⚠️ ห้ามกด "การทำให้ใช้งานได้รายการใหม่" ตอนอัปเดต เพราะจะได้ลิงก์ `/exec` ใหม่ และต้องแก้ `config.js` อีกครั้ง

# ความปลอดภัยของระบบ (สรุป)
- รหัสผ่านเก็บแบบ SHA-256 + salt วนซ้ำ 5,000 รอบ ไม่มีใครเห็นรหัสจริงในชีต
- บังคับเปลี่ยนรหัสเริ่มต้น · รหัสอย่างน้อย 8 ตัว · ผิด 5 ครั้งล็อก 15 นาทีและบันทึกไว้
- เข้าสู่ระบบได้นานสุด 12 ชั่วโมง · ปิดบัญชี/เปลี่ยนรหัส = ออกจากระบบทุกเครื่องทันที
- สิทธิ์รายคน ตรวจที่ฝั่ง Google ทุกคำสั่ง (ซ่อนปุ่มในหน้าเว็บอย่างเดียวไม่พอ ระบบตรวจซ้ำ)
- กันการฝังสูตรในชีต และกันโค้ดแฝงในรูปสินค้า
- หน้าเว็บมี Content-Security-Policy ส่งข้อมูลได้เฉพาะไป Google Apps Script
- ทุกการแก้ไขสำคัญมีบันทึก ใคร ทำอะไร เมื่อไร · สำรองไฟล์อัตโนมัติทุกสัปดาห์
